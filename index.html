本应用是一款纯本地、离线的字典 / 印谱 / 书法字典 PDF 索引查阅工具。 我们不设账号、不联网、不上传你的书籍、索引或使用记录。 本政策说明本应用会接触哪些信息、为什么接触，以及你可以如何管理这些数据。 请你在使用前完整阅读；你可以在应用内【设置】→【隐私政策】随时再次查看。

01我们收集哪些信息

本应用不收集、不上传任何个人信息。具体而言：

  • 不要求注册、登录，不收集手机号、姓名、身份证号、地址、通讯录、短信、位置、相册或设备标识；
  • 不接入第三方统计、广告、推送、支付、地图或社交 SDK；
  • 应用未申请 INTERNET 网络权限，因此不具备联网上传、云端同步或远程更新的能力；
  • 你在应用内创建的书名、索引、页码偏移、检索组、最近阅读页，只保存在本机应用私有目录，不会发送到任何服务器。

应用商店的下载、分发、评论与开发者后台数据，由各商店平台按照其自身的隐私政策处理，不属于本应用收集的数据。

本应用只在必要场景申请以下系统能力，且均由你在具体操作时触发：

03信息的存储与删除

3.1 存在哪里

书目与索引保存在本机应用私有目录，主要包括：

  • books.json：书目、原文件名、页码偏移、词条与阅读位置；
  • books.json.bak1 ~ bak3：每次保存时自动轮换的三份历史备份，用于防止写入中断损坏；
  • books/：索引副本、封面缓存，以及内置示例书自带的演示 PDF。

你的原始 PDF 不会被复制进应用。应用只记录系统授权位置（路径或 content:// URI）与登记时的原文件名。打开 PDF 时直接读取原文件；只有你主动使用“重命名”功能时，才会修改你选中的那个 PDF 的文件名。

3.2 备份包

【一键导出数据】生成的 zip 只包含书目、索引、页码偏移与检索组，不包含 PDF 原件，以避免手机里出现重复副本。备份包由你自行保存、转移或删除，应用不会自动上传。

3.3 删除方式

  • 在书库维护页删除某一本书：应用会删除该书在应用内的索引副本、封面缓存；不会删除你的原始 PDF；
  • 卸载应用：会删除应用私有目录中的全部数据。卸载前请先用【一键导出数据】自行备份；
  • 清空应用数据：效果同上，且会收回系统对原 PDF 的读取授权，需要重新选择或扫描关联。

04信息的共享、转让与公开披露

本应用不向任何第三方共享、转让或公开披露你的书目、索引、PDF 内容或使用记录。应用内不包含第三方 SDK；PDF 渲染、文件选择、分享截图等能力均使用 Android 系统组件完成。

除以下情形外，我们不会主动对外提供你的信息：

  • 你自行通过系统分享功能，把截图、备份包或索引文件发送给他人；
  • 法律法规规定、司法机关或监管机关依法要求提供。

05你的权利

  • 查看与更正：在应用内查看、修改书名、索引、页码偏移与检索组；
  • 删除：逐本删除书目，或卸载应用 / 清空应用数据；
  • 导出：通过【一键导出数据】把书目与索引导出为 zip，自行留存或迁移；
  • 撤回同意：本应用不收集个人信息；你可以停止使用、卸载应用或清空数据来终止本地数据处理。若系统权限已被授予，可在手机“设置 → 应用 → 索隐 → 权限”中随时关闭。

06未成年人保护

本应用是面向工具书查阅的通用工具，不面向未成年人收集任何个人信息，也不包含社交、直播、付费等面向未成年人的功能。未成年人应在监护人指导下使用；监护人如发现相关权益受到影响，可通过下方联系方式与我们联系。

07信息安全

本应用不联网，数据默认只存在于你的设备本地；应用使用系统应用私有目录保存书库与索引，并在每次保存时保留三份历史备份。安装包使用正式证书签名，并启用代码混淆与启动签名自校验，以降低被篡改后诱导安装的风险。

任何本地存储都无法承诺绝对安全。请妥善保管手机与备份文件，不要在不信任的设备上导入来源不明的备份包。
